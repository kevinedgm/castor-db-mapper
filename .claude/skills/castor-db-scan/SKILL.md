# Scan the project

1. Read repository-specific instructions (`AGENTS.md`, security policies) and do not execute application PHP.
2. From the Castor installation root run `python -m castor scan /absolute/path/to/project --full`. If using the module in the target project, `python -m castor scan . --full`.
3. Inspect `.castor/manifest.json` for counts, `.castor/graph.json` for evidence, `.castor/index.sqlite` for indexed retrieval, and `.castor/files.json` for per-file SHA caches. Ignore these generated files in version control unless explicitly approved.
4. Run `python -m castor report --output /absolute/path/to/project/.castor` (global `--output` precedes the command). Check `warnings` and unresolved dynamic SQL.
5. Use `.castor/graph.html` (generated by `visualize`) for an interactive overview.

SQL is extracted only from `.php`, `.phtml`, `.inc` and `.sql` in this release (see `castor/adapters/`). JS/TS/Vue/HTML files are read only for endpoint references. Do not claim SQL support for any other language. Classify declarations, observed joins, and heuristic links separately. Never run DB writes.
